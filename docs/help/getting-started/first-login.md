# 首次登录与修改初始密码

新数据库会创建唯一管理员 `admin`，初始密码为 `EanlRffYBYYo70pigl4y`。首次登录后必须立即修改密码，修改前不能访问业务数据或执行操作。

## 步骤

1. 打开部署地址，使用用户名 `admin` 和初始密码登录。
2. 在首次改密页面输入当前密码、新密码和确认密码；新密码长度为 8–1024 个字符。
3. 提交后重新使用新密码登录。

**成功标志：** 可以进入“工作”页面；旧的浏览器登录会话已失效。

## 失败排查

- 确认登录状态时网络或服务异常：只显示错误提示，不自动退出或清空当前页面。首次打开尚未完成验证时不会显示登录表单或业务内容；网络恢复后刷新页面重试。只有服务器明确确认未登录时才返回登录页。
- 忘记密码：只能在 Server 本机运行管理员重置命令，并通过 `MAR_RESET_PASSWORD` 传入新密码；系统不提供公开 HTTP 重置入口。
- 始终回到改密页：确认新密码与确认值一致，并使用当前登录会话的原密码。

安全提示：初始密码仅用于首次激活。不要保留在密码管理器的默认条目、脚本或部署说明中。
