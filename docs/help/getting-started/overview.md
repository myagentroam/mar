# MyAgentRoam 是什么

MyAgentRoam 是面向团队私有化部署、支持“工作 / 对话”两种模式的共享 Agent 工作台。团队只需在自己的 Windows、Linux 或 macOS 主机上配置一次 Agent、任意大模型、项目目录和工具链，就能把这个可直接工作的空间授权给成员。“工作”模式提供完整的 Node、Workspace、Agent 会话、文件、Git 和终端能力；“对话”模式让成员从管理员发布并授权的模板直接开始。无需在每台个人设备重复搭建环境。托管对话因依赖 Bubblewrap 沙箱，目前仅可由 Linux Node 承载。

工作区源码、外部 Agent 的本机凭据和终端留在团队自己的主机中；Server 管理的模型与凭据配置保存在 Server。MyAgentRoam 让获授权的成员共享工作环境并衔接进度，同时保留清晰的数据和权限边界。个人用户也可以用它统一管理自己的多台工作主机。

## 四个组件

| 组件   | 放在哪里     | 负责什么                              |
| ------ | ------------ | ------------------------------------- |
| Web    | 浏览器       | 工作台、对话、文件和终端界面          |
| Server | 你的服务器   | 登录、Node 登记、授权和浏览器连接     |
| Node   | 每台工作主机 | 工作区、Agent、文件、Git 与终端       |
| Agent  | Node 本机    | 使用团队接入的 Agent 与大模型完成工作 |

浏览器通过 Server 认证和授权，Node 主动向 Server 建立出站控制连接；普通工作区数据也可在授权后使用 WebRTC 直传。直传的网络条件和回退见[网络、TLS 与 WebSocket](../deployment/network.md)。每个 Workspace 属于一台 Node，不能跨 Node 混用文件、终端或会话。

## 界面语言

控制台和文档中心使用当前浏览器保存的语言选择；从控制台打开文档时会进入对应语言。登录或返回控制台时，当前浏览器语言会同步到账号并作为后续通知的生成语言；在设置中切换语言也会更新账号偏好。通知保存创建时的最终文案，切换语言不会改写已有通知。文档中心切换语言时会打开当前文档的对应语言版本；直接打开文档链接时，该链接的语言优先。

## 安装、界面缓存与更新

控制台会在首次联网打开时缓存应用界面所需的静态资源，避免之后反复下载相同文件。“设置 → 关于”可查看当前运行方式（浏览器标签页或 PWA 独立窗口）和应用资源缓存状态；运行方式表示当前窗口的打开方式，不表示此设备是否安装过应用。缓存可用时，断网也能打开应用外壳，但登录、会话、文件和终端等功能仍需联网。帮助文档和搜索不进入应用缓存。普通浏览器标签页与已安装应用使用相同机制；浏览器存储可能隔离或被回收，缓存不可用时仍可在线使用。

如需安装为独立应用窗口，可使用浏览器地址栏或菜单中的“安装应用”入口；支持添加到主屏幕的移动浏览器也可从分享或浏览器菜单选择“添加到主屏幕”。入口名称和位置因浏览器与操作系统而异，无需安装也可使用静态资源缓存。

离线资源不包含登录状态、权限、会话、工作区文件或终端。冷启动时若无法联系 Server，界面会显示身份尚未确认，可在恢复连接后打开帮助或重试；恢复连接后才能确认身份和使用依赖 Server、Node 的功能。已打开的页面不会仅因断网而退出登录。

新版资源准备完成后会显示更新通知，不会立即打断当前页面。点击通知、在“设置 → 关于”应用更新，或在更新已准备好后主动刷新页面，都会切换到已准备的新版本，并自动刷新所有已打开的同源应用窗口和标签页；无需逐个关闭、额外确认或等待编辑和文件传输结束。如果刷新时新版尚未准备好，本次页面会继续使用旧版，准备完成后再提示更新。自动切换失败不会循环重试，仍可手动应用更新。浏览器标签页与已安装应用行为一致。刷新可能丢弃未保存内容并中断文件传输，请按需先保存。旧版迁移或缓存受损时，可能需要联网、关闭所有同源应用窗口和标签页后重新打开应用。

## 最快成功路径

1. 完成[部署前准备](prerequisites.md)并部署 Server/Web。
2. 用 `admin` 首次登录并修改初始密码。
3. 在工作主机安装并注册 Node。
4. 登记一个工作区，确认所选 Agent 已登录可用。
5. 新建会话并发送第一条消息。

**成功标志：** “工作”模式的资源树显示 Node 在线；打开 Workspace 后能看到文件树，并能创建可发送消息的会话。

社区版适合单人使用，不限制登记 Node 数量；企业 License 启用组织、角色、共享、SSO 和审计。详情见[用户、组织与资源权限](../concepts/permissions-and-sharing.md)。

已有可用 Server 的用户可从[首次登录](first-login.md)、[接入 Node](connect-node.md)或[开始第一次 Agent 对话](first-agent-session.md)进入；管理员部署时从[部署前准备](prerequisites.md)开始。
