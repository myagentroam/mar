# 接下来可以做什么

首次在“工作”模式完成 Agent 会话后，可按任务选择“工作 / 对话”模式继续：

- 在[会话管理](../workbench/sessions.md)中查找、重命名、置顶或继续历史会话。
- 使用[`@` 引用、文件夹与附件](../workbench/file-reference-and-attachment.md)向 Agent 提供工作区材料。
- 在[文件](../workbench/files.md)、[Git Changes](../workbench/git-changes.md)和[终端](../workbench/terminal.md)中检查改动。
- 需要从固定模板快速开始时，进入[“对话”模式](../workbench/hosted-conversations.md)新建独立隔离的对话。
- 为多个主机重复[接入 Node](connect-node.md)；每台 Node 的工作区和 Agent 环境完全独立。
- 管理员可继续阅读[环境密钥](../administration/secrets.md)和[上线安全检查清单](../deployment/security-checklist.md)。

遇到问题时从[快速诊断](../troubleshooting/quick-diagnosis.md)开始。
