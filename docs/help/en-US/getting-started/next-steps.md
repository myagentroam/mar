# Next Steps

After completing your first Agent session in Work mode, choose Work or Conversation mode for the next task:

- Find, rename, pin, or continue sessions in [Session Management](../workbench/sessions.md).
- Give the Agent Workspace material with [`@` references, folders, and attachments](../workbench/file-reference-and-attachment.md).
- Inspect results in [Files](../workbench/files.md), [Git Changes](../workbench/git-changes.md), and [Terminal](../workbench/terminal.md).
- When you want to start quickly from a fixed template, use [Conversation mode](../workbench/hosted-conversations.md) for an independently isolated conversation.
- [Connect more Nodes](connect-node.md). Every Node has an independent Workspace and Agent environment.
- Administrators can continue with [Environment Secrets](../administration/secrets.md) and the [Production Security Checklist](../deployment/security-checklist.md).

When something fails, start with [Quick Diagnosis](../troubleshooting/quick-diagnosis.md).
