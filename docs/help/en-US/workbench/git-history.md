# Git History

Git History displays commits for the selected Git Workspace in reverse chronological order. Load older entries as needed and open a commit to inspect its metadata and file changes. Ctrl-click (Command-click on macOS) a changed file to open the same Diff tab in a separate window through the standard file preview/editor flow.

History is read-only. It does not switch branches, reset files, or change `HEAD`. Use the Workspace terminal or another approved Git client for repository mutations.

Missing history usually means the directory is not a Git repository, the Node service account cannot read it, or the current Node version does not support the feature.
