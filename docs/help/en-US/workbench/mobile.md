# Continue on Mobile

Mobile Workbench keeps the current Agent conversation as the main Work surface. Use **Work** in the top bar to open the existing Node → Workspace resource tree, or **Chat** to enter Conversation mode. Selecting Chat again while it is active opens the chat-history drawer. Skills, Admin, Settings, Notifications, Files/Changes, and Terminal retain their existing behavior.

The Composer stays above the on-screen keyboard. Enter inserts a newline; use the send button to submit. Agent and model controls remain compact, while file previews and diffs use the full viewport.

Closing the mobile Terminal drawer hides it without terminating the Node process. Explicitly close a terminal tab to stop it. All desktop authorization and Workspace boundaries still apply.
