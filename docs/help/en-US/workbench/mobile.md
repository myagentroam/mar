# Continue on Mobile

Mobile Workbench keeps the current Agent conversation as the main Work surface. Use **Work** in the top bar to open the existing Node → Workspace resource tree, or **Chat** to enter Conversation mode. Selecting Chat again toggles its history drawer. Work, Admin, and Settings menus also collapse when their active top-bar entry is selected again. Files/Changes remains available from the conversation title bar.

**Recent Sessions** and **Notifications** reuse the side menu used by Work, Admin and Settings, with a scrolling list. Use its close button, scrim, or active top-bar entry to dismiss it. Browser Back, including the browser's edge-swipe back gesture, closes the menu before leaving the current work surface. Switching entries replaces the current panel rather than stacking panels. Brief previews of new notifications do not automatically open the full panel or mark notifications read.

The Composer stays above the on-screen keyboard. Enter inserts a newline; use the send button to submit. Agent and model controls remain compact, while file previews and diffs use the full viewport.

Select **Open terminal** in the conversation title bar. Terminal slides up from the bottom as a full-width, half-screen sheet. Select the scrim above it to hide the sheet without ending the terminal; reopening preserves its tabs. Explicitly close a terminal tab to stop it. All desktop authorization and Workspace boundaries still apply.
