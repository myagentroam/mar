# Keyboard Shortcuts

Session shortcuts apply to the focused Main or Aside conversation. An open dialog prevents background commands from taking focus. Terminals and text editors retain their native input and shortcuts, except for the Terminal toggle. Shortcuts do not take over while an IME is composing.

With an Aside or file tab focused, use the arrow keys or Home/End to move focus, then press Enter or Space to activate it. Moving focus alone does not switch the content.

Mobile Enter always inserts a newline; use the send button to submit. `Ctrl/Cmd+F` and `Ctrl/Cmd+A` are intercepted only when the focused or active page explicitly provides internal Find or Select All; ordinary pages, forms, and native controls keep their browser or native behavior. `Shift+Tab` always retains its native focus or menu behavior. Shortcuts are disabled while an input method editor is composing text and may be unavailable while an operation is loading.

On mobile, tap the find icon in the preview actions to search within a text file or Diff.

Mobile browser Back closes the whole file window, not one file tab or a position in file-navigation history. Canceling an unsaved-change confirmation keeps the window open. Companion file pages and rendered previews use the same Back behavior.

`Ctrl+N`, `Ctrl+W`, and `Ctrl+Shift+W` work when the browser or PWA delivers the key event to the page. If the browser opens a new window or closes its own tab or window instead, use the corresponding `Alt` (`Option` on macOS) combination.

`Ctrl+Tab` and `Ctrl+Shift+Tab` are equivalent to `Alt+→` and `Alt+←`, cycling in visible tab order with wraparound; macOS also uses Control. With one Workspace tab or a repeated key, cycle shortcuts are consumed without reactivating the tab. Workspace switching, new-session, and close shortcuts also work in Composer; other inputs, editors, terminals, and dialogs retain their native behavior. Ctrl+Tab combinations also require the browser or PWA to deliver the key event to the page.

Numbered Workspace tab shortcuts use Control on all platforms and have no Alt/Option equivalent. Repeated keys are consumed without reactivating an existing target. If the browser handles `Ctrl+1…9/0` itself, click the Workspace tab or use `Alt+←/→` (`Option+←/→` on macOS).

When Prompt Tab is enabled in Work mode, press `Tab Tab` in the foreground Composer to request a prediction, or press one `Tab` while pending to cancel. With a suggestion, `Tab` accepts and `Esc` dismisses without stopping the Agent. Plain `Tab` always stays in the editor, even when prediction is unavailable; `Shift+Tab` keeps its original behavior. See [Prompt Tab](../workbench/composer.md#prompt-tab).
