# Account Security and Sign-in Sessions

Open **Settings → Account Security** to change your password with the current password and matching replacement values. Changing it revokes previous sign-in sessions.

Review device, IP address, sign-in time, and expiry in **Sign-in Sessions**. Revoke devices you no longer use or recognize. If several unknown sessions appear, change the password immediately and sign in again only on trusted devices.

Always sign out after using a public or temporary device. OAuth sign-in does not remove the need to protect the linked local account and active sessions.
