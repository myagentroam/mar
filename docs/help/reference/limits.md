# 版本、容量与已知限制

| 项目          | 当前边界                                                                         |
| ------------- | -------------------------------------------------------------------------------- |
| Node.js       | `>=22.13 <25`                                                                    |
| 社区版 Node   | 登记数量不受限制                                                                 |
| Terminal      | 每 Node 最多 10 个；每 Workspace 最多 5 个运行中终端                             |
| 会话运行      | 同一会话中的消息按队列顺序执行；不同会话可以并行                                 |
| 文件          | 仅已登记 Workspace 且在 `allowedRoots` 内                                        |
| 会话/终端恢复 | Node 重启会结束正在执行的任务、消息队列和终端；已保存的对话历史仍由各 Agent 管理 |
| 托管对话进程  | 单个本地进程最多 300 秒 CPU、64 个进程、256 个文件描述符和 1 GiB 单文件大小      |
| 移动端        | 支持阅读和常用操作；后台、终端、拖拽和复杂 Diff 受浏览器限制                     |

实际可用模型、思考等级、权限和上下文取决于 Node 当前发现的 Agent 配置。模型服务自身的容量和限额请以你的账号或服务配置为准。

MyAgentRoam 不额外设置沙箱进程的虚拟地址空间或 Conversation 级 RSS 上限，避免低 RSS 的大范围虚拟映射被误判为实际内存占用。承载 Node、容器或系统服务自身的内存限制仍然生效。
