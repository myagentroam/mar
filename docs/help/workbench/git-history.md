# 查看 Git 历史

Git History 展示当前 Workspace 仓库可读取的提交列表和提交 Diff。

## 前置条件

Workspace 必须是可读取 Git 仓库。历史读取不会 fetch 远程，也不会改变分支、暂存区或工作区文件。

## 步骤

1. 在右侧文件面板切换到“Git History”。
2. 需要时选择根仓库或已初始化子模块，并选择一个或多个本地/远程分支；页面不会自动执行 `git fetch`。
3. 点击提交展开该提交的文件树。文本文件显示相对上一提交的 Diff，根提交与空内容比较；支持的图片、音视频、PDF 和 Office 格式直接预览选定提交中的文件，不会读取当前工作区同名文件。按住 Ctrl（macOS 为 Command）点击文件会通过标准文件预览/编辑器链路在独立窗口打开相同内容，保留提交和仓库上下文。目标提交中已删除的文件不会自动切换到父提交或当前版本。
4. 每页默认显示 50 个提交，点击“加载更多”继续读取。需要最新的远程分支记录时，先在终端按你的 Git 流程执行 fetch，再刷新历史。
5. 历史页面是只读入口；回滚、切换分支或提交仍应在终端中明确执行。

**成功标志：** 提交顺序与所选仓库、分支的本地 `git log` 一致，展开提交后只显示该提交对应的文件和差异。

失败时检查该 Workspace 是否为 Git 仓库、服务账号是否有读取 `.git` 的权限。下一步：[使用 Workspace 终端](terminal.md)。

提交记录中的作者、消息和路径可能来自仓库自身；分享截图或导出前请按你的代码库安全规则审查。
