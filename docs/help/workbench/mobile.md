# 在移动端继续工作

点击会话标题栏的“打开终端”，终端会从底部向上展开为全宽半屏浮层。点击上方遮罩关闭只隐藏浮层，不结束终端；重新打开会保留原有标签。需要结束进程时显式关闭终端标签。

移动端适合查看会话、通知、文件和简短回复。顶部保留品牌 Logo，以及“工作”“对话”“最近会话”“管理”“设置”“文档”和通知入口；使用支持悬浮提示的设备指向 Logo 时可查看品牌名称和版本。“工作”打开既有 Node → Workspace 资源树，“对话”进入对话模式，再次点击已激活的“对话”可展开或收起历史抽屉。工作资源树、管理和设置菜单与文件面板按需展开，文件区域提示会简化为“文件”。

“最近会话”和通知复用“工作 / 管理 / 设置”的侧边菜单面板，列表可滚动。点击关闭按钮、遮罩或再次点击已展开的入口可收起；浏览器返回（包括手机浏览器侧滑返回）也会优先收起菜单，不离开当前工作面。切换入口不会叠加面板。新通知的短暂预览不会自动打开完整面板，也不会把通知标记为已读。

建议：使用“回到最新”阅读流式内容，后台或网络切换后重新打开当前会话确认状态；把长时间终端操作、拖动文件和复杂 Diff 审查留给桌面浏览器。活动会话继续由 Node 运行，关闭或切到后台不会自动停止它。

## 移动端检查

1. 打开当前会话前确认顶部 Node/Workspace 与预期一致。
2. 收到通知后进入对应会话，再检查其最终 Working/Idle 状态。
3. 文件操作优先使用查看、引用和简单预览；破坏性操作建议改在桌面端完成。

**成功标志：** 重新进入页面后能恢复当前 Workspace 和会话阅读位置，且 Node 上的运行状态与会话标题一致。

如果菜单遮挡、抽屉位置异常或页面长期空白，刷新一次当前页面；仍失败时记录设备/浏览器版本并查看[快速诊断](../troubleshooting/quick-diagnosis.md)。
