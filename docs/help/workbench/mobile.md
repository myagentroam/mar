# 在移动端继续工作

会话标题栏的“更多”统一打开辅助工作面，并恢复当前工作区上次激活的标签；文件、搜索、Git 和终端均在其中选择，不再分别提供文件、终端按钮。辅助工作面覆盖顶栏以下的区域，使用返回按钮或浏览器返回可回到会话而不结束终端；重新打开时保留原有终端标签。需要结束进程时显式关闭终端标签。

移动端适合查看会话、通知、文件和简短回复。顶部保留品牌 Logo，以及“工作”“对话”“会话与通知”“管理”“设置”和文档入口；使用支持悬浮提示的设备指向 Logo 时可查看品牌名称和版本。点击非当前的“工作”或“对话”只切换模式并恢复已有内容，不自动打开资源树或历史菜单；没有已选内容时显示已有空态。再次点击当前“工作”可展开或收起 Node → Workspace 资源树，再次点击当前“对话”可展开或收起历史抽屉。管理和设置保留既有分类菜单行为，文件面板从会话标题栏的“更多”进入辅助工作面后选择。

“会话与通知”统一打开包含“最近会话”和“通知”两个页面的自定义面板，不再保留独立铃铛；图标右上数字表示未读通知，右下绿点表示有普通会话正在运行。有未读通知时默认打开“通知”，否则打开“最近会话”。可点击图标或使用 `Ctrl/Cmd+Shift+E` 开合，点击外部或按 Escape 也可关闭，不响应悬停开合。

工作、管理和设置等顶栏菜单不另设 X 关闭按钮，点击遮罩、按 Escape 或再次点击已展开的入口可收起；浏览器返回（包括手机浏览器侧滑返回）也会优先收起菜单，不离开当前工作面。切换菜单入口不会叠加面板；切换工作或对话模式会收起已有菜单。有未读通知时保留“全部标记已读”操作；打开通知列表本身不会将全部通知标记已读。新通知的短暂预览不会自动打开完整面板，也不会把通知标记为已读。

浏览器返回也会优先关闭当前会话列表、文件或终端工具层，以及最上层文件、图片预览或任务弹窗，保留背后的工作面。编辑中的退出继续遵循该界面的原有提示；若出现放弃修改确认，再次返回会取消确认并保留修改。关闭预览不会下载或删除文件，收起终端不会结束进程。图库横滑、图片缩放和内容横向滚动不是返回操作；系统文件选择器等浏览器原生界面仍由系统处理。

HTML 预览使用同一辅助工作面；从源码预览时文件窗口暂时收起，返回源码可继续编辑草稿。详见[文件预览](files.md)。

建议：使用“回到最新”阅读流式内容，后台或网络切换后重新打开当前会话确认状态；把长时间终端操作、拖动文件和复杂 Diff 审查留给桌面浏览器。活动会话继续由 Node 运行，关闭或切到后台不会自动停止它。

## 移动端检查

1. 打开当前会话前确认顶部 Node/Workspace 与预期一致。
2. 收到通知后进入对应会话，再检查其最终 Working/Idle 状态。
3. 文件操作优先使用查看、引用和简单预览；破坏性操作建议改在桌面端完成。

**成功标志：** 重新进入页面后能恢复当前 Workspace 和会话阅读位置，且 Node 上的运行状态与会话标题一致。

如果菜单遮挡、抽屉位置异常或页面长期空白，刷新一次当前页面；仍失败时记录设备/浏览器版本并查看[快速诊断](../troubleshooting/quick-diagnosis.md)。
