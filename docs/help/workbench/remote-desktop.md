# 查看 Node 远程桌面

远程桌面用于查看获授权 Node 的当前交互桌面，不需要选择 Workspace。它不是新的系统登录会话，也不提供文件传输或提权。

随包 Linux x64 后端基于 Debian 12 构建，需要兼容的系统库和现有可访问的 X11 桌面。其他平台需要有可用的受管后端。

远程桌面没有独立开关，是否可用取决于 Node 能否访问图形桌面和受管后端。它与 Computer Use 相互独立；同时操作同一桌面时，输入可能相互影响。

显示器能力取决于平台后端。macOS 当前只分享主屏；仅在 Node 报告支持时提供多屏选择。Windows/macOS 修改显示配置后请重新连接。

画质可选低、中、高三档，默认中档。画质使用 VNC 后端的原生编码设置，不改变 Node 的显示分辨率；实际效果取决于后端和编码。

## 前置条件

- 当前账号具有目标 Node 的使用权；仅能管理 Node 或使用其中某个 Workspace 并不自动授予桌面使用权。
- Node 在线且实际报告远程桌面可用，目标系统有可访问的交互桌面和必要的系统权限。Linux 仅支持已有 X11 桌面，不支持 Wayland。
- 浏览器可以访问 Server；连接可能使用直接连接或 Server 中继，两种方式都需要 Server 授权。

## 操作

1. 在“工作”的 Node 操作菜单选择“远程桌面”。桌面在独立的同源浏览器标签页打开，不改变当前 Workspace，也不复用原标签页的连接。
2. 首次以只读方式显示原生主屏。后端支持多屏时，可使用显示器选择器切换某个屏幕或全桌面；显示内容为该 Node 的真实桌面。
3. 需要操作时点击“控制桌面”。其他人或程序也可能同时操作该桌面。
4. 在控制模式下，点击“发送剪贴板文本”并按浏览器提示授权，才会读取本机剪贴板并发送给远程桌面。随后在远程应用中执行粘贴操作。不会自动同步剪贴板；只读模式不能发送。

移动设备可以在控制模式打开“文本键盘”，先在本地输入框组合文字，再点击“发送文本”；也可以使用回车和退格按钮。文字通过远程键盘事件发送，实际输入效果取决于远程应用和系统。切换模式、隐藏页面或失去控制时未发送的文字会被清除。5. 失去窗口焦点时，本标签页停止人工输入；标签页隐藏时，无论模式如何都会结束该标签页的活动画面。返回后需主动重新连接。关闭标签页不会停止 Agent 任务。

浏览器可能保留部分系统快捷键；使用浏览器无法交给网页的按键时，请改用目标应用的界面操作。移动设备上的可用输入方式也受浏览器与设备限制。

## 常见问题

- **入口不可用：**确认 Node 在线、账号有 Node 使用权，且 Node 实际报告桌面能力可用。Linux 还需检查 X11 会话和所需系统库；不要通过开放公共 VNC 端口绕过授权。
- **连接中断或清理结果未知：**旧控制可能仍在安全收敛。不要反复切换模式；按页面提示刷新后重新尝试，并检查 Node、系统会话和权限。
- **锁屏或会话失效：**先在目标系统恢复有效交互会话，再重新连接。不要通过关闭系统安全控制来绕过限制。
