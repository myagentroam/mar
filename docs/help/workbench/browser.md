# 使用 Workspace 浏览器

在工作模式下，打开辅助工作面，然后选择标签栏末尾的「+ → 浏览器」。网页运行在当前 Workspace 所属 Node 的 Chromium 中，不是在你操作 Console 的设备上运行。当前账号在不同 Workspace 的浏览器数据分别保存。

## 让 MAR Agent 使用浏览器

「设置 → 浏览器」中的 **Browser Use** 默认开启。网页测试默认在 Node 自带的隔离 Chromium 中运行，不会使用你的登录态。可让 MAR Agent 加载 `mar-browser-use` 做网页验证；内置 `playwright-cli` 命令也可配合可选的 Playwright CLI Skill 使用，无需另外安装命令。项目已有的 Playwright 测试仍使用项目自己的测试入口。

任务需要当前页面、已有登录态或人工登录时，Agent 可用 Playwright 操作本工作区的共享浏览器，也可以先为你打开登录页。请在 MAR 浏览器里亲自登录，再告诉 Agent 继续。你可以离开辅助面，也可以和 Agent 同时操作同一个网页。Agent 操作时会短暂显示提示，不会阻止你的输入。关闭 Browser Use 会断开 Agent，不会关闭你的标签页。

## 浏览网页

- 手动关闭最后一个网页标签时，外层「浏览器」标签也会关闭，但不会结束共用的 Chromium 实例。
- 在地址栏输入 `? ` 加关键词并按回车，可显式使用 Google 搜索。普通输入仍按网址处理，不会作为搜索词发送。
- 支持的 Node 可通过「更多」重新打开已关闭的标签页；只重新加载网址，不恢复网页当时的状态。在「更多 → 缩放」中，用「−」和「＋」调整当前远端标签页，点击百分比回到 100%，不会缩放工作台。
- 投屏断开或切换页面后迟迟没有收到画面时，每次中断最多自动尝试一次重连同一实例，不重放旧操作。点一次「重连」可接回仍在运行的实例；如果原实例已结束，会打开新的空白浏览器。支持的 Node 可在错误提示或新空白页选择「重新打开最近的标签页」，加载上次看到的完整网址。超出恢复范围的网址会略过，不会按截短的网址打开。个别网页打开失败不会影响其他标签页；不会恢复未提交的表单或前进、后退记录。
- 点击右下角的「网页键盘模式」后，Tab 和 Shift+Tab 在远端网页内切换焦点；Esc 退出并把焦点还给工作台。触屏上可用同一入口打开设备键盘。
- 支持的 Node 可选择「保存到工作区」，把已完成的下载直接复制到当前工作区。请输入含文件名的相对路径；目录必须已存在，不会覆盖同名文件，也不会删除下载暂存。

在网页区域按 **Ctrl+F**（macOS 为 **⌘F**），或选择 **更多 → 在网页中查找**。输入文字后会高亮匹配并显示序号；按 **Enter** 或 **Shift+Enter** 循环跳转，按 **Esc** 关闭。查找的是远端网页上的可见文字，包括开放 Shadow DOM 中显示的文字，不是本机控制台文字。

- 在地址栏或空白页中央的输入框输入 HTTP(S) 地址并按 Enter，在当前标签导航。省略协议时，普通主机默认使用 HTTPS；`localhost` 和 `127.0.0.1` 默认使用 HTTP。
- 输入时可看到当前 Node 浏览器的历史匹配项（标题和网址）。用方向键选择并按 Enter，或直接点选，即可在当前标签打开；按 Esc 可关闭建议。MAR 不会另外保存历史，也不会读取你设备浏览器的历史。
- 使用工具栏后退、前进、刷新或停止加载。点网页标签末尾的「+」可新开标签。地址栏旁的外部打开按钮将当前实际 URL 原样交给你的设备浏览器。
- 同一账号可以在多个设备或窗口同时打开同一个 Workspace 浏览器，共享当前网页和标签。在支持视口调整的 Node 上，网页按最先连接的浏览器面板尺寸排版。该窗口断开后，由下一个已连接的面板接续，不会重新加载网页。「更多 → 关闭浏览器」会关闭共用实例，影响所有窗口。
- 双方支持高清时，ICE 直连默认以最高 1080p 起播。画质会自动随连接调整；中继使用标准画质。小窗口不会被放大，降档也不改变网页布局。
- 点浏览器右下角的 Info 图标，可查看当前连接方式、接收码率、绘制帧率、网页 CSS 视口、解码分辨率及编码。解码画面可以小于网页视口，但不改变网页布局。静止网页可能没有新画面，显示零不代表断线。
- 在 MAR 中，`localhost` 和 `127.0.0.1` 指 **Node 的回环地址**。可直接打开 Workspace 终端中启动的服务地址，无需登记端口。用外部浏览器打开同一 URL 时，回环地址则指 **你的设备**。
- 网页要求上传时，从本机选择文件。网页发起的下载会自动开始，浏览器会短暂提示，文件先存到 Node；只有点击「保存到本机」才会传到你的设备。工具栏「更多」左边的下载按钮以角标显示进行中数量。打开列表可查看已下载大小和可用的总大小、取消下载、查看失败或取消结果，也可以查看已完成文件的大小并保存到本机。删除已完成的下载会移除 Node 暂存。即使浏览器一直开启，Node 也会定期清理已结束满 30 天的下载；暂存空间或记录数较多时，旧项可能更早清理。关闭浏览器实例也会清理 Node 暂存。建议及时保存重要文件，清理不会影响已保存到本机的副本。
- 在触屏上，轻触点击，滑动滚动远端网页；支持原生触控的 Node 也可拖动网页滑块等控件。输入文字时，先点网页里的输入框，再用画面右下角的键盘按钮打开或收起键盘。
- 选中远端网页中的文本后，可通过画面右下角的「复制网页所选文本」复制到本机。要粘贴纯文本，先点选远端网页的输入框，再点「粘贴纯文本」或使用本机的粘贴快捷键。
- 在支持右键菜单的 Node 上，右键选区可复制，右键输入框可粘贴纯文本，右键链接可复制地址或在新标签打开。网页自己接管右键时，不会叠加 MAR 菜单；需使用 MAR 的复制或粘贴时，先选中文字或聚焦输入框，再用 Shift+右键、菜单键或 Shift+F10 打开菜单。如果设备浏览器不允许菜单读取剪贴板，请使用粘贴快捷键。

## 选择链接打开位置

在「个人设置 → 浏览器」分别设置公网链接和本地链接的打开位置。默认情况下，Workspace 会话和终端中的公网 URL 在外部浏览器打开，Node 回环 URL 在 MAR 打开；受控 Workspace HTML 文件链接在辅助工作面打开预览。按住 Ctrl（macOS 上是 ⌘）点击可反转去向。这些设置只保存在当前 Console 浏览器并按账号区分，不影响地址栏或网页内的链接。

## 登录、浏览数据与历史

打开浏览器会直接进入空白页或恢复已有实例，默认按账号和工作区保存网站登录状态和站点数据。收起辅助工作面或关闭 Browser 标签不会立即关闭 Chromium 实例；在支持前台续时的 Node 上，只要浏览器面板保持在前台并已连接，就不会因未操作而超时。离开面板或切到其他 Console 标签页后，若 15 分钟没有浏览器操作（包括 Agent 操作），且下载没有收到新数据，实例会关闭。「更多 → 关闭浏览器」会结束实例并关闭辅助面中的浏览器标签。保存的浏览器数据连续 30 天未使用后由 Node 回收。

每个 Node 最多同时运行 16 个 Workspace 浏览器实例。达到上限时，只有未连接工作面或 Agent、也没有进行中的数据操作或下载的实例可以回收。Node 优先关闭最久未活动的实例；如果没有符合条件的实例，暂时无法打开新的浏览器。

在工具栏「更多」中选择「清理浏览器缓存」，会打开当前浏览器的清除数据弹窗，不离开网页。确认 Workspace 和浏览器资料后，选择时间范围与数据类别；默认只选择缓存。浏览器还会按容量自动回收 HTTP 磁盘缓存，不自动删除 Cookie 或站点数据。手动删除 Cookie 和站点数据可能使网站退出登录，不会删除 Workspace 文件、已下载文件、MAR 登录或设备浏览器数据。

选择「更多 → 浏览历史」查看按日期分组的网页。输入标题或网址即可搜索，也可点「按日期筛选」。点击结果可在 MAR 新标签重开，使用行菜单可单独移除。要批量删除，可勾选多行或点「全选本页」，然后点「删除所选」。确认后会移除该资料中所选网址的全部访问记录。

在「更多 → 浏览器设置」中可以设置账号的**缓存清理周期**，范围 1–60 天，默认 30 天。保存后，下次打开工作区浏览器时自动生效。自动清理只处理 HTTP 缓存，保留登录状态、历史和下载。用主导航的「工作」回到工作台。
