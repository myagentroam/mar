# 使用 Workspace 浏览器

在工作模式下，打开辅助工作面，然后选择标签栏末尾的「+ → 浏览器」。网页运行在当前 Workspace 所属 Node 的 Chromium 中，不是在你操作 Console 的设备上运行。当前账号在不同 Workspace 的浏览器数据分别保存。

## 浏览网页

- 在地址栏或空白页中央的输入框输入 HTTP(S) 地址并按 Enter，在当前标签导航。省略协议时，普通主机默认使用 HTTPS；`localhost` 和 `127.0.0.1` 默认使用 HTTP。
- 使用工具栏后退、前进、刷新或停止加载。点网页标签末尾的「+」可新开标签。地址栏旁的外部打开按钮将当前实际 URL 原样交给你的设备浏览器。
- 在支持此功能的 Node 上，调整工作台窗口、拖动分隔线或旋转设备时，网页会按浏览器面板的尺寸重新排版，不会重新加载。
- 双方支持高清时，ICE 直连默认以最高 1080p 起播。画质会自动随连接调整；中继使用标准画质。小窗口不会被放大，降档也不改变网页布局。
- 点浏览器右下角的 Info 图标，可查看当前连接方式、接收码率、绘制帧率、网页视口及编码。静止网页可能没有新画面，显示零不代表断线。
- 在 MAR 中，`localhost` 和 `127.0.0.1` 指 **Node 的回环地址**。可直接打开 Workspace 终端中启动的服务地址，无需登记端口。用外部浏览器打开同一 URL 时，回环地址则指 **你的设备**。
- 网页要求上传时，从本机选择文件。网页发起下载后，文件先自动下载到 Node，不会自动保存到你的设备。工具栏「更多」左边的下载按钮会提示列表更新；打开后可查看进度、取消下载，或选择「保存到本机」。下载文件在 MAR 浏览器实例关闭时从 Node 清理；请在关闭前保存需要的文件。
- 在触屏上，轻触点击，滑动滚动远端网页；支持原生触控的 Node 也可拖动网页滑块等控件。输入文字时，先点网页里的输入框，再用画面右下角的键盘按钮打开或收起键盘。
- 选中远端网页中的文本后，可通过画面右下角的「复制网页所选文本」复制到本机。要粘贴纯文本，先点选远端网页的输入框，再使用本机的粘贴快捷键。
- 在支持右键菜单的 Node 上，右键选区可复制，右键输入框可粘贴纯文本，右键链接可复制地址或在新标签打开。网页自己接管右键时，不会叠加 MAR 菜单；需使用 MAR 的复制或粘贴时，先选中文字或聚焦输入框，再用 Shift+右键、菜单键或 Shift+F10 打开菜单。如果设备浏览器不允许菜单读取剪贴板，请使用粘贴快捷键。

## 选择链接打开位置

在「个人设置 → 浏览器」分别设置公网链接和本地链接的打开位置。默认情况下，Workspace 会话和终端中的公网 URL 在外部浏览器打开，Node 回环 URL 在 MAR 打开；受控 Workspace HTML 文件链接在辅助工作面打开预览。按住 Ctrl（macOS 上是 ⌘）点击可反转去向。这些设置只保存在当前 Console 浏览器并按账号区分，不影响地址栏或网页内的链接。

## 登录、浏览数据与历史

打开浏览器会直接进入空白页或恢复已有实例，默认按账号和工作区保存网站登录状态和站点数据。收起辅助工作面或关闭 Browser 标签不会立即关闭 Chromium 实例；连续 15 分钟没有视图附着时，实例会关闭。「更多 → 关闭浏览器」会结束实例并关闭辅助面中的浏览器标签。保存的浏览器数据连续 30 天未使用后由 Node 回收。

在工具栏「更多」中选择「清理浏览器缓存」，会打开当前浏览器的清除数据弹窗，不离开网页。确认 Workspace 和浏览器资料后，选择时间范围与数据类别；默认只选择缓存。删除 Cookie 和站点数据可能使网站退出登录，不会删除 Workspace 文件、已下载文件、MAR 登录或设备浏览器数据。

选择「更多 → 浏览历史」查看按日期分组的网页。输入标题或网址即可搜索，也可点「按日期筛选」。点击结果可在 MAR 新标签重开；使用行菜单可单独移除，勾选多行可「删除所选」。确认后会移除该资料中所选网址的全部访问记录。「更多 → 浏览器设置」则前往个人设置，只管理链接打开位置；用主导航的「工作」回到工作台。
