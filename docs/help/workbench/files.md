# 浏览、搜索与管理文件

文件面板以懒加载树展示当前 Workspace。文件和文件夹可点击，鼠标悬停可展开更多操作。

## 前置条件

当前 Workspace 在线可读；创建、重命名、移动和删除还需要 Node 服务账号文件权限及当前用户的资源运行权。

## 步骤

1. 在右侧选择“文件”，展开文件夹并点击文件。文本、Diff、图片、PDF、Office、视频和音频都会在同一文件 Tab 条中打开；每个 Tab 显示文件名和完整路径提示，内容页可以独立切换并保留自己的状态。Tab 内的 × 只关闭对应文件，顶部右侧的“关闭文件窗口”会关闭全部文件 Tab 并返回工作台；在独立文件窗口中则关闭该浏览器窗口。存在未保存修改时会先确认，取消任一确认会保留全部 Tab。`Ctrl+W`／`Alt+W` 关闭当前文件 Tab，`Esc`／`Ctrl+Shift+W`／`Alt+Shift+W` 关闭整个文件窗口；Esc 优先关闭最上层查找、菜单或设置弹窗。移动端浏览器返回同样关闭整个文件窗口，取消未保存确认后保持当前窗口。独立文件页与无 Tab 的独立渲染预览沿用相同逻辑；Ctrl 组合只在浏览器交付按键时生效，可使用 Alt 替代。文件树按目录逐层加载；目录底部出现“加载更多”时，点击后继续读取该目录。使用顶部“显示过滤”可按名称或相对路径筛选当前已加载的文件和目录，清空输入即可恢复原树；该过滤不会读取尚未展开的目录。
2. 使用“快速打开”的“全部 / 工作区 / 会话 / 文件 / 符号”页签查找目标。工作区只按展示名称匹配，不匹配路径或 Node 名称；会话只匹配当前工作区已加载会话的标题。所有结果先按匹配度排序，仅在同分时按工作区、会话、文件、符号排列；同为符号时定义先于引用。符号需输入完整名称；定义可先出现，引用稍后补充。选择会话会在当前工作区打开该会话；选择符号或文件后，页面会切回“文件”并立即建立预览，文件树在后台展开它的上级目录并滚动定位。选择工作区会切换或打开对应标签。文件名重复时，可以输入空格分隔的词进一步匹配相对路径，例如 `app src` 定位 `src/app.ts`，词的顺序不限；根目录文件也可输入 `foo.ts:12` 跳到指定行。当前工作区的路径索引按需建立，第一次使用可能显示“正在准备索引”。不同结果类型独立显示进度、失败或超时；结果不完整时可缩小查询，有失败详情和重试入口。使用“搜索”页签可按文件内容查找，并从结果跳到命中行。默认按普通文本搜索；需要模式匹配时，勾选搜索框上方的“使用正则表达式”后再搜索。无效模式会提示错误。
3. 文件或文件夹名称过长时，会在文件树中省略显示；将鼠标悬停在行上可查看完整相对路径。当前预览文件会在树中保持选中样式。
4. 将鼠标移到文件或文件夹行上，点击 `…`：文件可下载、复制相对路径、重命名或删除；文件夹可新建文件、新建文件夹、上传、复制相对路径、重命名或递归删除。
5. 把文件或文件夹拖到另一个文件夹可移动；不能覆盖同名目标，也不能把文件夹移动到自身或其下级目录。
6. 支持写入的 Node 会让完整 UTF-8 文本默认以编辑模式打开；可在“设置 > 外观”改为默认只读，也可在预览标题栏临时切换。按 `Ctrl/Cmd+S` 或保存按钮写入，按 `Ctrl/Cmd+F` 查找，按 `Ctrl/Cmd+H` 在相同工具栏中查找替换，按 `Alt+M` 打开符号表并跳到类、函数或章节。补全只使用当前文件和语言基础语法，不是项目级语言服务。超过 1 MiB 的文本仍可编辑和保存，但会使用纯文本模式并关闭语法解析、符号表和补全，以控制浏览器内存占用。
7. 支持代码导航的 Node 中，按住 `Ctrl/Cmd` 悬停代码符号可识别可跳转项；单击后候选先显示定义，再显示引用。选择目标会在文件预览顶部新增标签页、定位并选中目标行。在文件预览内按 `Alt+Left` / `Alt+Right` 可在代码跳转位置及手动切换的文件 Tab 之间后退、前进，并恢复光标位置；关闭的 Tab 不再进入历史导航。首次打开源码会在后台建立本地索引，构建期间的跳转会等待同一次构建完成。正式支持 TypeScript/JavaScript、Python、Java/Kotlin、Go、Rust、C/C++ 和 C#；其他 Ctags 内置语言仅尽力支持。
8. 按 Ctrl/Cmd 点击文件可在同一个复用的独立 Console 窗口中打开文件，便于同时保留聊天窗口；窗口会自动选择对应 Workspace，并使用与主窗口完全相同的全屏文件 Tab、编辑、保存、查找和代码导航能力。后续打开直接在该 Console 的文件 Tab 条中累计或激活，不刷新窗口，也不会持续创建新窗口；在独立窗口按 `Ctrl+R` 刷新仍保持文件窗口并打开最近打开的文件。文本正文和 Git Diff 正文右键提供复制、粘贴、重新加载；只读内容不可粘贴，重新加载未保存的编辑内容需先确认。Markdown 的渲染预览使用另一个无文件 Tab 的独立页面，普通打开仍以源码文本页开始。
9. 打开 Markdown 文件后，使用标题栏的预览图标在新页面查看渲染结果。独立页固定使用浅色，不跟随控制台主题，正文采用适合打印的 A4 排版，可通过浏览器刷新更新内容。预览设置可开启全浏览器共用的文本水印，启用状态和文本只保存在本浏览器，不提供主题选择。Markdown 支持 Mermaid 图表；相对链接和图片只能访问当前 Workspace 内的文件，`http`/`https` 外部图片会由浏览器直接加载。
10. HTML/HTM 文件普通打开显示源码；点击预览图标或按 `Ctrl/Cmd+Shift+V`，在独立窗口运行 HTML 和 JavaScript。页面可加载所在目录及下级目录的脚本、样式、图片等资源，也可向外网发起请求并发送文件内容。预览页提示运行风险。管理员可在“系统配置”设置独立 HTTPS 预览域名；未配置时使用当前控制台域名，**HTML 脚本以当前用户权限运行，不与工作台隔离**。仅预览信任的文件；独立域名需要事先配置 DNS、证书和指向 Server 预览路由的反向代理。跨域 HTML 正文不能向控制台交付按键，使用关闭快捷键前请先点击预览页标题区；移动端浏览器返回仍可关闭预览窗口。

Markdown/HTML 独立渲染页保留浏览器原生右键菜单，不使用普通文件页的复制、粘贴和重新加载菜单。

统一预览窗口支持代码与文本、常见图片、PDF、DOCX、XLSX、PPTX、常见视频和音频。PDF 由工作台自身渲染，不依赖浏览器是否启用内置 PDF 阅读器；PDF 与媒体按需读取，现代 Office 文件在浏览器本地解析，不会发送到第三方预览服务。PPTX 会同时受可用宽度和高度约束，在超宽或较矮的窗口中保持完整幻灯片比例。旧版 DOC、XLS、PPT 及其他不支持的格式会保留下载入口。单个 Office 文件过大或内容损坏时也会提示改为下载。

普通工作模式中的聊天文件链接和图片链接支持 Node 服务账号可读的绝对路径，包括 Workspace 外的会话图片目录；相对路径仍指向当前 Workspace。绝对路径仅用于只读预览和下载，不扩大文件树、搜索或写入范围，也不适用于托管对话。**拥有 Workspace 访问权的用户可通过绝对路径读取 Node 服务账号可读的其他宿主文件；Workspace 和允许根目录不是文件保密边界。** 共享 Node 时应使用合适的服务账号和操作系统文件权限隔离敏感数据。

**成功标志：** 预览标题与树中选中路径一致，刷新树后仍显示真实文件系统结果。

## 失败排查

- 若取消或移除时提示未能确认临时上传已清理，任务会保留而不是静默消失。请重试或联系管理员核查 Node 临时上传状态；刷新页面不会确认清理结果。
- Workspace 文件直传会校验完整文件的 SHA-256，校验失败不会替换目标。已开始的上传中断会报错，不会自动重试、重新授权或改走 Server 从零重传。请主动点击重试；刷新页面后需重新选择同名、同大小且内容未变的源文件，再经新授权从 Node 确认的连续进度恢复。临时上传过期或 Node 重启后需重新上传。开始直传前不可用时仍可回退 Server 上传；下载与预览的既有回退行为不变。
- 操作被拒绝：检查 Node 服务账号权限、Workspace 边界和资源授权。旧 Node、不支持写入的 Node、截断文本、Diff 和 Git 历史内容会自动保持只读。
- 正则内容搜索不可用：正则模式依赖 Node 随包提供的 `rg` 资源。重新安装或升级该 Node 后重试；普通文本搜索仍可在资源缺失时回退执行。
- 保存冲突：文件已被 Agent、终端或另一窗口修改。关闭当前修改并重新打开文件，确认最新内容后再编辑；工作台不会强制覆盖。
- 预览是 Diff：聊天内文件更改和 Git 文本变更默认进入 Diff；Git Changes / Git History 中支持的图片、音视频、PDF 和 Office 格式直接预览对应工作树或选定提交中的文件。未知二进制及不支持的格式保留降级入口。

删除和覆盖外的文件操作直接作用于 Node 上的真实目录，没有隐藏回收站；执行重命名、移动或删除前先确认 Git 状态或备份。下一步：[查看 Git Changes 与 Diff](git-changes.md)。

## 常见失败

- 拖动后无变化：目标目录可能无写权限、属于边界外路径或在拖动过程中发生变更；刷新树后重新选择。
- 文件名很长：将鼠标悬停在树行上查看完整相对路径，再执行删除或移动。
- 新标签无法打开：允许浏览器弹出新标签。执行型 HTML 在当前域名运行时可能使用当前登录用户已有的权限。
- Office 预览失败：确认文件是 DOCX、XLSX 或 PPTX，而不是仅修改了扩展名的旧格式；仍可使用下载按钮在本机应用中打开。
