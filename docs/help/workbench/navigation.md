# 工作模式、Node 与 Workspace

控制台提供并列的“工作”和“对话”两种模式。“工作”是原“节点”顶级菜单的新名称，仍打开同一棵 Node → Workspace 资源树；Node 管理、Workspace 标签、Agent 会话、文件、Git 和终端功能都没有变化。“对话”模式用于从已发布模板直接创建和继续对话。

本页说明如何在“工作”模式中切换工作目录，并且不影响运行中的会话。

主导航中“对话”后的“会话与通知”图标统一打开最近会话和通知：右上数字是未读通知数，右下绿点表示有普通会话正在运行。两者独立显示，不再保留右上角铃铛。保留范围和排序见[会话阅读说明](conversation.md)。

点击图标或使用 `Ctrl/Cmd+Shift+E` 打开最近会话／通知自定义面板。再次点击图标、使用同一快捷键、点击外部或按 `Esc` 关闭。桌面和移动端均不响应悬停开合，移出图标或面板也不会自动关闭。每次打开时，有未读通知默认显示“通知”，否则显示“最近会话”；展开后由你选择页面，不叠加入口文字提示。

## 前置条件

已登录且至少有一个可见 Node。节点离线时仍可激活已打开的工作区标签，但文件、会话和终端等实时操作不可用。

## 步骤

1. 打开主菜单“工作”，在左侧资源树展开在线 Node，选择一个已登记 Workspace。
2. Workspace 在顶部以标签页打开；再次选择其他 Workspace 会创建或激活相应标签。
3. 每个工作区标签都独立保留会话列表、文件树和阅读位置；所有工作区使用同一切换流程：立即激活目标标签并恢复缓存，再后台检查最新状态；没有缓存时显示目标加载态，不等待网络才切换。
4. 使用刷新按钮只在需要重新发现会话或文件时刷新，避免打断阅读位置。

点击工作区标签（包括当前标签、桌面溢出菜单和移动端标签）时，有未读则打开该工作区第一个有效未读会话；成功打开后只标记该会话已读，其他会话未读保留。没有未读就恢复上次会话，不因其他会话运行而跳转；无历史选择沿用原有空态或草稿。定位时同步主/子分类。打开失败不清除未读；后台状态变化不自动导航，运行点仅提示。资源树、快捷键与关闭标签后的回退行为不变。

Node 只用于资源树分组和主机管理。点击 Node 名称只展开或收起该组，不改变当前工作区，也不保存独立的“当前 Node”。登记新工作区时选择的是此次登记的目标主机，关闭登记弹窗不会切换现有工作区。

Aside 左侧保留文件、搜索、Git 变更、Git 历史和终端等固定工具；打开的会话和 HTML 浏览器位于其右侧，可通过标签上的 × 关闭。浏览器仅在预览 HTML 后出现，同一工作区始终复用一个浏览器页面。

聚焦 Aside 标签栏、内容或 Composer 后，也可用 `Ctrl+W` / `Alt+W` 关闭当前会话或浏览器，不影响工作区、会话草稿和运行任务；固定工具不会被关闭。按键边界与跨域预览限制见[键盘快捷键](../reference/keyboard-shortcuts.md)。

桌面可拖动工作区树右侧和 Aside 左侧的分隔线调整宽度，调整范围受最小、最大宽度及可用空间限制。Aside 的文件等工具使用紧凑宽度，会话、终端和浏览器使用独立的内容宽度；两种偏好分别保存在当前浏览器并在刷新后恢复。首次使用或保存值损坏时采用相应默认宽度。桌面空间不足时工作面上下排列，移动端使用抽屉；这些布局不提供横向调宽，也不会覆盖已保存的桌面偏好。

右键点击工作区标签，选择“固定”可将其放到固定区末尾。固定标签不显示关闭按钮，而显示固定图标，点击图标或右键选择“取消固定”后回到普通区。固定项之间可以拖动重排；把固定标签拖到普通标签之后会自动取消固定，把普通标签拖入固定区内部会自动固定，放在两区边界则仍为普通标签。固定状态和顺序会在刷新后恢复。桌面空间足够时固定区保持可见，只滚动普通标签；固定项过多、普通区空间不足或使用移动端时整体滚动；桌面可通过“全部已打开工作区”菜单访问溢出项，移动端使用横向滑动。

右键菜单的“前移”和“后移”每次移动一格，首尾会禁用无效操作，跨区前移或后移也会自动固定或取消固定。打开菜单、固定或调整顺序不会切换当前工作区，也不改变最近使用时间。最多保留 8 个普通标签，超过时按最近最少使用（LRU）淘汰；固定标签不占该配额，也不会被淘汰。取消固定导致超额时保留该标签并淘汰其他最久未使用的普通标签。

`Ctrl+W` 或 `Alt+W` 关闭当前普通标签，`Ctrl+Shift+W` 或 `Alt+Shift+W` 关闭全部普通标签，macOS 的 Alt 使用 `Option`；固定标签不会关闭，右键“关闭”在固定状态禁用。关闭快捷键在 Composer 内也生效，其他输入框、编辑器、终端和弹窗仍保留原生行为；连按 `Esc` 不再关闭工作区。Ctrl 组合需浏览器/PWA 将按键交给页面，若被浏览器拦截请使用 Alt 组合。关闭当前标签后返回最近使用的剩余标签，不受固定状态或显示顺序影响；目标已经失效时继续尝试下一标签，无剩余有效标签时保持未选择工作区；临时网络失败不切回旧标签，用户的新选择不会被迟到响应覆盖。关闭其他标签不切换工作区。关闭标签会清理其缓存并关闭所属终端，但不会注销工作区或停止运行中的 Agent。详见[快捷键](../reference/keyboard-shortcuts.md)。

**成功标志：** 面包屑、会话列表和右侧文件面板都对应当前标签的 Node 与 Workspace。

状态点表示 Node/会话近期状态：绿色表示可用或活动，灰色表示空闲或未加载，黄色/离线提示需进一步查看详情。切换 Workspace 不会停止该 Node 上仍在运行的 Agent 或关闭终端。

移动端通过顶部菜单按“工作、对话、管理、设置”切换；“工作”打开 Node → Workspace 资源树，“对话”进入对话模式，再次点击已激活的“对话”可打开历史抽屉。其他面板也会以抽屉形式展开。管理菜单不再提供独立“技能中心”，“技能配置”“技能源管理”“环境密钥”连续排列，“MCP 源管理”仍作为独立管理分区；技能配置页面内可切换 Skill 与 MCP。设置菜单包含“账户安全”“外观”“系统通知”“快捷提示词”“个性化提示词”“快捷键”和“关于”；“个性化提示词”用于为当前账号的后续 Agent 执行提供额外指引，按公共、MAR Agent、Codex、Claude Code、OpenCode 分别保存；MAR Agent 标签在中英文界面中都固定显示为 `MAR Agent`。执行时自动使用公共内容与当前 Runner 专属内容，不会修改 Node 或 Workspace 的 `AGENTS.md`、`CLAUDE.md`。“外观”默认使用深色配色与 Material 文件图标，可切换浅色/深色配色及 Seti/Material 图标主题。选择立即生效且只保存在当前浏览器；已保存的有效选择不会被默认值覆盖，终端始终保持固定深色配色。“关于”可查看当前 Web 版本、打开文档中心，并按类别查看 Web、Server、Node/MAR Agent、随包工具、图标与可选 Computer Use Runtime 的主要开源组件。这是精选展示，不是完整依赖清单。“查看 Web 第三方许可声明”只覆盖 Web；Server、Node 和可选运行时的许可与声明应查看对应发行包，Node 依赖的 `@myagentroam/binaries` 包内分别通过 `vendor/ripgrep/` 与 `vendor/ctags/` 提供工具材料。外部 Agent、SDK 和单独安装工具仍适用各自条款。系统运行状态和 License 管理位于管理员的“系统信息”。下一步：[创建、查找与管理会话](sessions.md)。

## 常见失败

- 系统通知未弹出：先在“设置 → 系统通知”主动开启并允许浏览器权限，再检查浏览器的网站通知权限、操作系统通知开关及勿扰模式。HTTP 内网地址通常不可用，请使用 HTTPS。

- 标签打开后内容空白：确认所选 Node 在线，再关闭并重新打开当前 Workspace；不要因此删除 Workspace 登记。
- 标签已切换但加载失败：临时网络错误会留在目标工作区，可重试或切换其他标签；确认工作区不存在或失去访问权限后会清理其内容并按标签规则回退。若目标有缓存却未恢复，请记录工作区及发生时间用于排查，不要删除登记。
- 看不到 Workspace：检查它的归属/共享权限，或请资源管理员确认登记。

## 主题

主题仅保存在当前浏览器，不上传、不随账号或设备同步；清理浏览器数据会删除自定义主题，可导出 JSON 文件备份或手动迁移。

1. 打开 **设置 → 主题**。主题选择器通过色块展示内置浅色、默认深色与已保存主题。点击主题仅查看配色，点击 **应用主题** 才切换；内置主题可查看、复制和导出，不可覆盖或删除。
2. 打开任意主题的更多操作菜单，选择 **复制副本**，将完整配色复制到新草稿；也可 **导入 JSON**。导入不覆盖同名主题，副本和导入草稿均需保存。
3. 左侧编辑 JSON，右侧通过静态样例紧凑预览列表、消息、代码/Diff、状态提示、输入框和按钮，不代表真实项目内容。可悬停或用 Tab 检查控件状态；点击 **放大预览** 以正常字号查看同一样本。窄屏下预览位于编辑器下方，编辑不改变当前全局主题。
4. **保存主题**后，可在主题选择器中点击 **应用主题**，也可在 **设置 → 外观 → 主题** 选择启用。应用已保存主题不会替换当前草稿。修改正在使用的主题并保存会立即更新配色。离开页面前请保存草稿。
5. 支持复制 JSON、格式化和导出。**重置**经确认恢复上次保存的 JSON，或导入/复制时的初始草稿，不会删除主题。从更多操作菜单删除自定义主题时需要确认，删除当前主题后回退默认深色。

JSON 使用 `version: 1`、`name` 和 `colors`，不再使用 `base`。`colors` 是颜色变量到颜色值的映射，例如将 `--mar-bg-panel` 设为 `#ffffff`。支持 `#RGB`、`#RGBA`、`#RRGGBB`、`#RRGGBBAA`；缺少或无效颜色统一使用默认深色主题的对应颜色，保存的原文不强制补齐。点击 JSON 标题旁的问号打开“主题颜色说明”，按分组查看色块和简短用途，支持搜索及复制变量名。深浅主题使用同一套 `--mar-*` 变量；组件库变量由内部映射。仅当前注册的 `--mar-*` 颜色字段生效；`--el-*` 和已移除字段视为未知字段，应用时忽略，不提供旧主题兼容。复制副本会展开完整有效配色，不依赖原主题。

只有 **JSON 语法错误**阻止保存或导出。缺失名称、未知字段或变量、无效颜色及低对比度只提示警告。保存和导出保留未知与无效内容，但应用时忽略；旧 `base` 字段也仅保留并提示未知字段，不再改变缺色回退规则。不执行任意 CSS、URL 或脚本。对比度检查仅覆盖显式填写的不透明颜色组合，不代表完整的可访问性认证。

主题不改变布局、字体、文件图标主题、终端固定配色或公开帮助。预览是代表性颜色样本，不执行真实工作台操作，也不覆盖终端等不受控区域。

## 系统通知

在“设置 → 系统通知”按本端能力开启，默认关闭，仅对当前浏览器与账号生效；只有主动操作才申请权限。

- **PC：失焦系统通知。** 工作台保持连接时，切到其他标签页、终端、IDE 或最小化仍可提醒；关闭全部工作台页面后不接收新通知，PC 不提供离线 Push。
- **移动端：离线推送。** 不弹实时失焦系统通知。手机退后台通常会断开连接；只有同账号全部工作台连接离线后，新通知才向已登记移动端推送。PC 即使失焦，只要仍连接就会抑制手机 Push。
- **站内通知：** 前台查看其他目标时，在“会话与通知”入口旁显示预览（移动端在顶栏下方），不替换已展开的菜单；正在查看目标时沿既有规则标记已读。后台不展开卡片，刷新、重连和重新聚焦不补弹历史。外部通知开关和权限不影响站内记录。

新的运行、审批、计划、待回答、定时任务及 Agent 显式消息保留原有适用范围。点击系统通知聚焦或打开控制台，只标记该条已读并定位目标；已删除、过期或无权通知不会导航。上传和 Web 更新仅站内展示，邮件仅按明确请求发送。

移动 Push 还需要管理员在“管理 → 系统配置”开启默认关闭的“Web Push 推送”，并配置有效 VAPID 联系地址（`MAR_WEB_PUSH_SUBJECT`，接受 `mailto:` 或 HTTPS；HTTPS 站点默认沿用公开 Origin）。个人页面分别显示偏好、浏览器权限及订阅状态；“管理员未开启”和“服务器尚未配置”不是浏览器拒绝权限。需要操作时点击“启用 / 重试离线推送”。单端关闭不影响其他端；不会补发在线或关闭期间的历史通知。

**升级后重新启用：** 旧 Push 登记会一次性清理，通知记录、已读与其他用户数据保留。刷新或关闭当前浏览器的全部旧工作台标签页，再在移动端新页面主动启用；准备或取消旧订阅失败时先重试，不要混用旧页面。PC 旧订阅会退役且不再登记。

Windows、macOS 和 Linux 使用浏览器通知接口，横幅、声音和勿扰行为由系统决定。浏览器通常要求 HTTPS 或受信任 localhost，并提供 Notifications API 与 Service Worker；项目按实际能力和权限判断，不额外禁止 HTTP。移动端还需要可用 Web Push，iOS/iPadOS 请使用支持的主屏幕 Web App 并主动授权。普通 iOS 标签页、断网、省电、浏览器完全退出和系统限制下不承诺送达。实际订阅使用浏览器返回的标准 HTTPS endpoint，不按厂商限定；Server 出站网络隔离由部署策略负责。

退出或撤销 Session 后相应移动绑定失效；迟到、无法确认绑定的 Push 只显示通用提示，点击仅打开控制台。已出站消息不能保证撤回，厂商接受不等于系统展示。若无横幅，检查网站权限、系统通知设置和勿扰模式；失败不会丢失站内通知。

## 用量统计

打开“设置 → 用量统计”，查看当前账号的 Agent 用量，默认展示“对话请求”中主 Agent 与子 Agent 的 Token 和调用数。顶部“对话请求 / 上下文压缩 / 输入预测”分别为独立统计项，标题生成与其他调用也可单独查看；上下文压缩和输入预测不计入“对话请求”。切换统计项同时更新滚动 24 小时和滚动 7 天（168 小时）概览、图表和明细；顶部当前统计项概览不随下方筛选变化。图表和明细可按时间、Runner、模型、工作／对话模式筛选，时间使用页面标明的浏览器时区。

自定义日期范围最多 90 天，可以包含未来时间（例如选择完整的当前月），也可以完全位于未来。统计只包含截至本次刷新时已入账的数据，未来部分没有数据。

模型排行和筛选按 Runner、Provider 和配置身份区分。MAR Agent 即使上游模型 ID 相同，个人、组织及 Fast 等不同配置也分别统计；其他 Runner 使用其原生模型 ID。历史记录缺少配置身份时按已记录的模型回退，不推断配置归属。使用组织配置产生的消耗仍计入发起人的个人用量，不表示使用了个人凭据。

页面可见时每 60 秒自动刷新，切到后台或离开后暂停；刷新失败会保留已有数据并稍后重试。翻页、排序或展开明细时，概览继续更新，明细保留当前浏览内容；选择“更新明细”或“刷新”可回到最新第一页。明细每次加载 20 条。桌面端使用统一管理分页控件显示真实总记录数和总页数，可直接跳页；移动端滚动接近底部时自动追加，加载失败可在原位重试。桌面列排序作用于当前页，移动端作用于已加载明细。筛选或主动刷新会重置已加载内容。自定义日期范围不会随自动刷新移动。上次刷新时间不代表所有 Node 均已完成同步。

输入包含缓存读取和缓存写入部分，输出包含可识别的推理部分；缓存与推理明细不再重复加入总量。各统计项分别记录会话主/子 Agent、上下文压缩、输入预测、标题生成等已观测请求，不互相混算；失败或取消请求仍保留上游已返回的用量，缺失的 Token 字段按 0 记录和展示；总量为输入与输出之和，后续收到用量更新时修订原记录。

概览、筛选合计、趋势、Runner／模型分布及明细均显示缓存读取量，并在括号内显示命中率（已记录缓存读取 Token ÷ 已记录输入 Token），汇总按 Token 加权，不取各请求百分比的平均值。趋势中的缓存色块是输入的一部分，不额外增加柱高或总量；悬浮提示和展开明细另列缓存写入量。未上报的缓存量显示 0；输入缺失或为零时命中率显示 0%。无调用的时间段也统一显示零。这是已记录用量的统计口径，不代表上游已确认没有消耗。
