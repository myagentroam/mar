# 终端无法打开或频繁断线

1. 确认 Node 在线且当前用户拥有该 Workspace 的终端运行权。
2. 检查 Node 服务账号是否能启动默认命令行（Linux/macOS 为该账号的 Shell，Windows 为命令提示符或 PowerShell）。
3. 确认未达到每 Node 10 个、每 Workspace 5 个的运行中终端上限；关闭不再需要的标签。
4. 检查反向代理是否允许 WebSocket Upgrade 和长连接；短暂网络断开后应自动尝试重连和有限输出回放。

**成功标志：** 新终端打开到预期 cwd，输入输出稳定；重连后不会重复执行已发送的输入。

Node 重启、显式关闭、权限丢失会终止终端，不能恢复为原进程。移动端后台限制较强，长操作请使用桌面端。

安全提示：排查 Shell 时避免执行会输出全部环境的命令；优先检查服务状态、可执行文件路径和最小无敏感输出的诊断命令。
