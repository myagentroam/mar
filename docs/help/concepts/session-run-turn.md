# 会话、运行与消息队列

- **会话**是会话列表中的一条持续对话，可以在以后重新打开。
- **当前任务**从一条消息真正开始执行，到 Agent 完成、失败或被停止为止。
- **一轮对话**包含你的消息，以及它之后连续出现的 Agent 回复和工具记录。

同一会话一次只执行一个任务。运行中继续发送的普通消息进入页面底部的消息队列并按顺序执行；不同会话可以同时运行。点击停止会暂停本会话的后续队列，避免未确认的消息自动开始。使用 `Ctrl+Enter` 优先补充时，投递方式取决于 Agent 和执行状态：支持原生补充的 MAR Agent 可在安全边界接收，其他情况下可能先停止当前任务；详见 [Composer](../workbench/composer.md)。

编辑队列消息时，按 `Enter` 保存，按 `Shift+Enter` 或 `Alt+Enter` 换行，按 `Ctrl+Enter` 立即执行。编辑状态下点击“立即执行”或按 `Ctrl+Enter`，系统会先保存编辑框中的当前内容，再立即执行该消息；如果保存失败，则不会执行。

| 状态    | 用户看到的含义         | 建议操作                   |
| ------- | ---------------------- | -------------------------- |
| Working | 正在启动、运行或停止中 | 等待、查看工具卡或选择停止 |
| Idle    | 当前没有正在执行的任务 | 直接发送下一条消息         |
| Queued  | 消息已排队尚未开始     | 调整、删除或等待前一项完成 |

Node 重启会结束当时的进程和终端，但已经写入 Agent 历史的对话仍可重新读取。普通 Workspace 的 MAR Agent 在正常退出时可有条件地交接未完成任务、Goal 和队列，不能保证异常退出或任意备份后恢复；见[会话恢复](../workbench/sessions.md#正常停止后的自动续作)。浏览器刷新不会主动停止 Node 上仍在运行的任务。
