# 文件、Git 与终端

文件树、Git 和终端以 Node 上的 Workspace 为工作上下文，不会先上传完整工作区到 Server。

桌面端的辅助工作面（Aside）与主对话左右并排。窗口过窄、无法同时容纳两者时，辅助工作面会暂时隐藏，不会改为上下各占一半高度；可放宽窗口或收起左侧资源栏来恢复。当前页签、草稿和宽度偏好保留，已打开的终端不会结束。移动端仍通过“打开辅助工作面”进入覆盖式工作面，返回后继续主对话。

- `@` **引用**告诉 Agent 使用工作区里的文件或文件夹，不等同于上传附件。
- **附件**上传当前消息需要的独立内容；它与工作区路径是两套语义。
- **文件预览**用于读文件；Git 文本变更和聊天中的文件更改默认打开 Diff，避免把改动误看成普通版本。Git Changes / Git History 中支持的图片、音视频、PDF 和 Office 格式直接预览对应工作树或选定提交中的文件。
- **终端**由 Node 服务账号启动；收起终端面板或切换工作区不会关闭它，显式关闭终端标签或重启 Node 才会终止对应进程。

文件操作受当前授权及各自路径规则限制；终端和 Agent 工具以 Node 服务账号权限执行。Workspace 与 `allowedRoots` 不是宿主机机密隔离边界，获授权的绝对路径读取可能访问该账号可读的其他文件。用操作系统账号和文件权限保护敏感目录。详细操作见[文件](../workbench/files.md)、[Git Changes](../workbench/git-changes.md)和[终端](../workbench/terminal.md)。

## 选择正确入口

当你希望 Agent 自己读取当前代码时使用 `@` 引用；当你需要把工作区外的内容作为这条消息输入时使用附件；当你要确认 Agent/你自己已改动什么时看 Diff；当你要执行受控本机命令时打开终端。四者可组合，但不会因此获得额外的 MAR 资源授权。

对文件进行重命名、移动或删除前先检查 Git 状态。MyAgentRoam 不把这些操作变成版本控制，也不会在删除后保留隐藏回收站。
