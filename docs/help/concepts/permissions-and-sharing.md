# 用户、组织与资源权限

社区版只有固定管理员 `admin`，登记 Node 数量不受限制。企业 License 激活后可使用组织、角色、资源共享、SSO 与审计。

| 界面角色                | 主要范围                                                   |
| ----------------------- | ---------------------------------------------------------- |
| 系统管理员（ADMIN）     | 系统功能及全部 Node 的登记治理；资源使用仍受归属和授权限制 |
| 组织管理员（ORG_ADMIN） | 管理本组织及子组织允许的用户和资源                         |
| 成员（MEMBER）          | 使用自己的个人资源及被授权的组织资源                       |

Node 和 Workspace 分别属于个人或组织。个人资源不可共享；组织资源可按用户或组织授权，选择根组织即覆盖全企业，不再使用单独的“整个企业”层级。授权会开放对应资源的使用权，但不授予删除、再授权或改变归属的权力。

每次资源操作都会重新检查当前授权。只获 Workspace 授权时，Server 仅依据 Node 的正式资源回执确认会话、Run 与终端归属，不从消息、日志或工具输出推断；无法确认归属或归属冲突时拒绝请求，不退回更宽的 Node 权限。

审计中的会话名称与 Run 关联为尽力补充，可能因缓存淘汰或断连而缺失；这不改变资源权限，也不影响操作结果。

系统管理员可查看并治理全部 Node，包括其他用户的个人 Node，因为 Node 登记会占用 Server 连接与管理资源；该能力不等于取得 Node、Workspace、文件、终端或 Agent 的使用权，也不会扩展到个人模型、凭据或目录。组织管理员仍只管理其组织子树。

License 冻结时系统保持已配置资源的可读和日常运行，管理面写操作受限；导入有效 License 后恢复。下一步：[管理用户、组织与角色](../administration/users-organizations.md)。
