# 账户安全与登录会话

目标是维护自己的密码和登录安全。

## 前置条件

已使用本地密码登录。SSO 用户是否可修改本地密码取决于管理员的账号配置；不要将浏览器 Cookie 交给他人。

## 步骤

1. 在“设置 → 账户安全”修改密码，输入当前密码与两次新密码。
2. 在“登录会话”中核对设备、IP、登录时间和有效期；可以单独注销不再使用或不认识的设备。
3. 发现多个未知设备时立即修改密码，系统会撤销原有登录，然后只在可信设备重新登录。
4. 使用公共或临时设备完成工作后，点击“退出登录”。

**成功标志：** 新密码可登录，旧登录 Cookie 不再可访问受保护页面。

失败时确认密码长度为 8–1024 个字符。管理员忘记密码只能由 Server 本机运维重置，详见[首次登录](../getting-started/first-login.md)。

安全提示：修改密码会撤销其他登录会话；在多设备环境中准备好重新登录，不要多人共用同一浏览器配置。
