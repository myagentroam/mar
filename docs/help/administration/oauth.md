# 配置 OAuth 2.0 SSO

企业版支持手工配置 OAuth 2.0 授权码登录，不提供 OIDC 自动发现。

## 适用范围

只配置身份服务明确支持的 OAuth 2.0 授权码流程。不要把未经验证的 Token 或 UserInfo 原文写入审计、截图或支持工单。

## 前置条件

准备身份服务提供商给出的授权地址、令牌地址、用户信息地址、Client ID、Client Secret，以及能唯一标识用户的字段路径。创建配置后，界面会显示该来源专用的回调地址 `/api/oauth/<providerKey>/callback`，把基于 `MAR_PUBLIC_ORIGIN` 生成的完整 HTTP 或 HTTPS 地址登记到身份服务提供商；提供商可能自行要求 HTTPS。

## 步骤

1. 打开“管理 → OAuth配置”，点击新增，填写不可重复的来源标识和登录页显示名称。
2. 填写三个 HTTPS 地址、Client 认证方式、PKCE 选项和用户字段映射。
3. 保存后点击测试，确认页面显示测试成功；配置被修改后会自动停用，必须重新测试。
4. 测试成功后启用该登录来源；确实需要自动创建用户时再打开自动开户。

**成功标志：** 登录页出现对应名称的入口，用户授权后能回到 MyAgentRoam，并匹配已绑定账号或按已配置策略登录。账户绑定成功或失败都会回到账户安全页，并显示结果提示；例如身份已被其他本地账号绑定时，请使用原账号登录或联系管理员处理。

失败时检查 `MAR_PUBLIC_ORIGIN`、回调白名单、HTTPS、JSON Pointer 与身份服务中的 Client 配置。Client Secret 不会回显，更新其他字段时留空表示保留原值。

自动开户默认关闭；开启后新用户固定进入根组织并成为“成员”。企业 License 冻结时不会执行新绑定、邮箱匹配或自动开户，已绑定的有效用户仍可按策略登录。
